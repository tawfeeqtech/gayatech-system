## 📋 نظرة عامة

نظام غايتك هو منصة ويب متكاملة لإدارة العمليات المالية والتشغيلية لشركة غايتك من مكان واحد. يوفر النظام تتبعاً دقيقاً للعملاء، العقود، المشاريع، الإيرادات، المصاريف، الموظفين، الشركاء، الاشتراكات، وتحويلات العملات.

### 🎯 الهدف
توفير رؤية شاملة للوضع المالي والتشغيلي للشركة في أي وقت، مع ضمان دقة البيانات ومنع ازدواجية احتساب الإيرادات.

---

## ✨ المميزات

### 🏢 **إدارة العملاء**
- سجل شامل للعملاء مع كافة البيانات
- ربط العميل بعدة عقود ومشاريع في نفس الوقت
- سجل كامل لتاريخ التعاملات المالية
- متابعة الأرصدة والديون

### 📋 **العقود الشهرية**
- إدارة العقود المستمرة مع العملاء
- توليد تلقائي للفواتير الشهرية
- إمكانية تغيير القيمة لكل شهر بشكل مستقل
- متابعة حالة السداد لكل شهر

### 🚀 **المشاريع**
- تتبع المشاريع المستقلة
- توزيع المهام على الموظفين
- متابعة حالة التنفيذ والتسليم
- ربط المدفوعات بالمشاريع

### 💰 **الإدارة المالية**
- دفتر معاملات مالية كامل
- دعم أنواع متعددة: دخل، مصروف، تحويل
- منع ازدواجية احتساب الإيرادات
- توزيع الدفعات على عدة فواتير

### 🏦 **الحسابات والمحافظ**
- إدارة عدة حسابات (الشركة، ريم، نقد)
- تتبع الأرصدة بشكل لحظي
- سجل حركة لكل حساب

### 👨‍💼 **الموظفون**
- سجل كامل للموظفين
- إدارة الرواتب والسلف
- ربط الموظفين بالمشاريع والمهام
- تتبع الأداء وساعات العمل

### 🤝 **الشركاء والتمويلات**
- تسجيل تمويلات الشركاء
- متابعة المسددات والمستحقات
- اعتبار التمويلات التزامات وليست إيرادات

### 📊 **التقارير ولوحة التحكم**
- 13 تقريراً مالياً وتشغيلياً
- لوحة تحكم تفاعلية
- رسوم بيانية وتحليلات
- تصدير PDF و Excel

### 🔔 **الإشعارات**
- تنبيهات الفواتير المستحقة والمتأخرة
- تنبيهات انتهاء الاشتراكات
- إشعارات الرصيد الدائن
- تنبيهات المهام المتأخرة

### 👥 **الصلاحيات والأدوار**
- 5 أدوار: مدير، مالي، مشاريع، محاسب، موظف
- صلاحيات مخصصة لكل دور
- حماية المسارات والعمليات

### 📥 **استيراد البيانات**
- استيراد من Excel
- قوالب جاهزة للتحميل
- معاينة قبل الاستيراد
- التحقق من صحة البيانات

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية

- **Node.js** (الإصدار 18 أو أحدث)
- **MongoDB** (محلي أو MongoDB Atlas)
- **npm** أو **yarn**

### التثبيت المحلي

```bash
# 1. استنساخ المشروع
git clone https://github.com/username/Gayatech-system.git
cd Gayatech-system

# 2. تثبيت جميع الحزم (الرئيسية + الخادم + العميل)
npm run install:all

# أو تثبيت كل جزء منفصل:
npm install                # الحزم الرئيسية
cd server && npm install   # حزم الخادم
cd ../client && npm install # حزم العميل

# 3. إعداد متغيرات البيئة
# انسخ ملف .env.example إلى .env في كل من server و client
cp server/.env.example server/.env
cp client/.env.example client/.env

# 4. تعديل متغيرات البيئة حسب إعداداتك
# - MONGODB_URI: رابط قاعدة البيانات
# - JWT_SECRET: مفتاح التشفير
# - المنافذ والإعدادات الأخرى

# 5. إدخال البيانات الأولية (اختياري)
npm run seed

# 6. تشغيل المشروع في وضع التطوير
npm run dev
المنافذ الافتراضية
الخدمة	المنفذ	الرابط
الواجهة الأمامية	5173	http://localhost:5173
الخادم الخلفي	5000	http://localhost:5000

حسابات افتراضية للتجربة
الدور	اسم المستخدم	كلمة المرور

📖 طريقة الاستخدام
1. إضافة العملاء
bash
العملاء ← إضافة عميل جديد ← تعبئة البيانات ← حفظ
2. إنشاء عقد شهري
bash
العقود الشهرية ← إضافة عقد ← اختيار العميل ← تحديد القيمة والتواريخ ← حفظ
3. إضافة مشروع
bash
المشاريع ← إضافة مشروع ← اختيار العميل ← تحديد التفاصيل ← حفظ
4. تسجيل معاملة مالية
bash
المعاملات المالية ← إضافة معاملة ← تحديد النوع والحساب ← توزيع إن لزم ← حفظ
5. استيراد البيانات
bash
استيراد البيانات ← اختيار النوع ← تحميل القالب ← تعبئته ← رفعه ← معاينة ← استيراد
