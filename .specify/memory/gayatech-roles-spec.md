# Spec: نظام الصلاحيات - Gayatech System

## Overview
نظام تحكم بالصلاحيات 5 مستويات مع حماية كاملة على Frontend و Backend

## Roles (موجود في User model)
| الدور | المفتاح | الصلاحيات |
|--------|---------|-----------|
| مدير النظام | admin | كل شيء |
| مدير مالي | finance | فواتير، مصاريف، حسابات فقط |
| مدير مشاريع | pm | عملاء، مشاريع، عقود فقط (بدون أرقام مالية) |
| محاسب | accountant | إدخال فواتير ومصاريف فقط (لا يحذف) |
| موظف | employee | راتبه ومهامه فقط |

## Acceptance Criteria
1. **Backend**: كل مسار API يتحقق من دور المستخدم قبل تنفيذ الطلب
2. **Frontend**: السايد بار يخفي الأقسام غير المسموحة لكل دور
3. **Frontend**: وصول مباشر لرابط غير مسموح → رسالة "غير مصرح" بدلاً من التوجيه
4. **Frontend**: Dashboard يعرض محتوى حسب الدور
5. **Frontend**: الأرقام المالية مخفية عن pm
6. **Accountant**: لا يرى أزرار الحذف
7. **Employee**: يرى فقط راتبه وبياناته
